# ATM System – Python

A command-line ATM System developed using Python as my final project for Harvard's CS50P (Introduction to Programming with Python).
#### Video Demo: https://youtu.be/kTZn2lYwy1A
## Project Overview

This project simulates basic ATM operations while implementing Python programming concepts such as functions, exception handling, file handling, JSON data storage, and automated testing.

## Features

- Account creation with PIN authentication
- Secure PIN validation with limited attempts
- Deposit money
- Withdraw money
- Check account balance
- View transaction history with timestamps
- Persistent account data using JSON storage

## Technologies Used

- Python
- JSON
- Pytest

## Project Files

| File | Description |
|---|---|
| `project.py` | Main ATM System application |
| `test.py` | Automated tests |

## How to Run

Run the program using:
python project.py
## How to Test
Run the tests using:
pytest
